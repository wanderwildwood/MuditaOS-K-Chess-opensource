# Initial info

* Kompakt-ui (UI components, typhography, theme)
* Sentry (error tracking)

## Code conventions

* official [kotlin conventions](https://kotlinlang.org/docs/coding-conventions.html)
* models naming convention:
    * `User` - domain model
    * `UserEntity` - database model
    * `UserUi` - ui model
    * `UserArg` - navigation model
