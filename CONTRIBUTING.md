# Contributing

This is a personal fork built for one specific device (Mudita Kompakt) and one person's use case (adding a local 2-player mode), not an actively maintained community project. The branch/commit/Jira workflow from Mudita's original internal repo doesn't apply here.

That said, if something here is useful to you, feel free to open an issue or a pull request — no promises on response time, but they're welcome.

For Mudita's own contribution process, see [mudita/MuditaOS-K-Chess-opensource](https://github.com/mudita/MuditaOS-K-Chess-opensource).
